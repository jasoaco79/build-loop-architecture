CoS Jev router

How a deliverable gets assigned and closed out across the wider stack (this repo's own writer race on plates 01–07 already ran this exact pattern in 2026-09-19's PR history):

A — who/whether. Decide who, if anyone, picks up the work before it starts.

B — one writer lane up front. A single lane is named for a deliverable; it's not a race by default.

C — stage-and-close, conditional. Only when two or more clean PRs land for the same deliverable does CoS Jev stage the winner and close the losers — a fallback, not the default.
